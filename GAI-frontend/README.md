# GAI Frontend

React + Vite frontend for Green Africa Institute.

## Run
```bash
npm install
npm run dev
```

Frontend: http://localhost:5173

Set `VITE_API_URL=http://localhost:5000/api` in `.env` to connect to the backend.

## Admin
Open `http://localhost:5173/admin-login` after the backend is running and an admin account has been created.
